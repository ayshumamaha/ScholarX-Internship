# Retrieval-Based Chatbot Using Python

## 1. Project Overview

The Retrieval-Based Chatbot is a Python application that answers user questions by searching a predefined knowledge base. It compares the user's question with stored questions and retrieves the most relevant answer.

The project demonstrates basic chatbot development, text processing, and information retrieval using Python.

## 2. Objectives

- Develop a simple chatbot using Python.
- Understand retrieval-based chatbot concepts.
- Create a question-and-answer knowledge base.
- Compare user questions with stored questions.
- Retrieve relevant responses.

## 3. Tools & Technologies Used

- **Programming Language:** Python
- **Concepts:** Text Processing and Information Retrieval
- **Techniques:** Word Matching and Similarity Scoring
- **Editor:** VS Code / Python IDLE

## 4. Features Implemented

- **Knowledge Base:** Stores predefined questions and answers.
- **Text Processing:** Cleans and prepares user questions.
- **Question Matching:** Finds the closest matching stored question.
- **Answer Retrieval:** Displays the corresponding answer.
- **Fallback Response:** Handles unknown questions.
- **Interactive Chat:** Supports multiple questions in one session.

## 5. Application Workflow

1. Start the chatbot.
2. Load the knowledge base.
3. Enter a question.
4. Process the question.
5. Compare it with stored questions.
6. Retrieve the closest matching answer.
7. Display the response.

## 6. How to Run the Project

1. Install Python.
2. No external libraries are required.
3. Save the code as `chatbot.py`.
4. Run the program:

   `python chatbot.py`

5. Enter questions in the terminal.

## 7. Expected Output

The chatbot accepts questions from the user and displays relevant answers from its knowledge base. If a suitable answer is not found, it displays a fallback message.
