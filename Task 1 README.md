# Document Classifier Using Python

## 1. Project Overview

The Document Classifier is a Python-based machine learning application that automatically categorizes text documents into predefined categories such as Technology, Sports, and Business.

The project uses TF-IDF for text feature extraction and the Multinomial Naive Bayes algorithm to train a classification model. Users can enter new text and receive a predicted category.

## 2. Objectives

- Develop a document classification application using Python.
- Understand basic Natural Language Processing concepts.
- Convert text into numerical features.
- Train a machine learning classification model.
- Predict categories for new documents.

## 3. Tools & Technologies Used

- **Programming Language:** Python
- **Library:** Scikit-learn
- **Techniques:** TF-IDF and Naive Bayes
- **Editor:** VS Code / Jupyter Notebook

## 4. Features Implemented

- **Sample Dataset:** Uses built-in labelled text documents.
- **Text Processing:** Converts text into numerical features.
- **Model Training:** Trains a Naive Bayes classifier.
- **Document Prediction:** Predicts the category of entered text.
- **User Interaction:** Accepts multiple text inputs.

## 5. Application Workflow

1. Load sample documents.
2. Prepare the text and category labels.
3. Convert text into TF-IDF features.
4. Train the classification model.
5. Enter a new document.
6. Predict and display its category.

## 6. How to Run the Project

1. Install Python.
2. Install Scikit-learn:

   `pip install scikit-learn`

3. Save the code as `document_classifier.py`.
4. Run the program:

   `python document_classifier.py`

## 7. Expected Output

The application trains a document classification model and asks the user to enter text. It displays the predicted category, such as Technology, Sports, or Business.

## 8. Conclusion

The Document Classifier demonstrates the use of machine learning and Natural Language Processing for automatic text categorization. It provides practical experience in text vectorization, model training, and prediction using Python.
